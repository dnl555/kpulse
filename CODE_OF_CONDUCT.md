# Code of Conduct

kpulse is a small open source project. Anyone is welcome to use it, file issues, or contribute.

## What we expect

- Be respectful and patient. Assume good intent.
- Keep discussion focused on the technical topic at hand.
- When you disagree, critique the idea, not the person.
- Help newcomers when you can. Everyone is learning.

## What is not acceptable

- Personal attacks, insults, or harassment of any kind.
- Discriminatory comments or jokes (about identity, background, ability, etc.).
- Sustained off-topic disruption.
- Publishing private information about others without permission.

## Scope

This applies to all project spaces: the GitHub repository (issues, pull requests, discussions, commits), and any other communication channel maintained by the project.

## Reporting

If you experience or witness a violation, contact the maintainer at **contact@kpulse.io**. Reports are handled privately. The maintainer will reply within a reasonable time and decide on any action needed, which can include a warning, removal of a comment, or a ban from the project.

## Acknowledgement

This code is intentionally short. For a more detailed framework, see the [Contributor Covenant](https://www.contributor-covenant.org/) which inspired the spirit of this document.
