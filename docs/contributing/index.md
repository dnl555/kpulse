# Contributing

Thanks for considering a contribution. kpulse is a small project and contributions of any size are welcome.

## Ways to contribute

There are many ways to contribute:

- **Suggest new features** &mdash; open an issue with the `enhancement` label and describe the use case.
- **Report issues** &mdash; bugs, confusing docs, surprising defaults.
- **Fix issues** &mdash; pick anything labelled `good first issue` or `help wanted`.
- **Improve documentation** &mdash; you're reading it. Typos and clearer examples are very welcome.

If you're not sure where to start, open an issue and ask.
